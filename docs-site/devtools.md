# 网页开发者工具

进入要检查的网页后，按 Ctrl+Shift+J 打开控制台。从 0.1.0-preview.38 起，F12 或 Ctrl+Shift+I 可以打开或关闭开发者工具。已有的自定义快捷键优先。地址栏左侧的站点菜单也提供控制台和网页源代码入口。新配置文件默认启用系统插件，已有配置保持原有启用和授权状态。

从 0.1.0-preview.34 起，开发者工具默认停靠在被检查的标签页。工具停靠时会跟随原网页隐藏或恢复。窗口空间不足时会自动打开独立窗口。也可从「… → 开发与诊断」选择「在独立窗口打开开发者工具」。调试期间，后台标签会保留，关闭工具后恢复常规内存调度。

从 0.1.0-preview.63 起，可在普通窗口的「… → 开发与诊断 → 开发者工具设置」中选择默认打开方式。设置保存在当前浏览器配置文件中，下次打开工具生效。调试时也可从同一菜单直接停靠或分离当前工具。打开控制台或资源面板会沿用当前工具的位置。

- **打开网页控制台**。查看日志并在当前网页上下文使用 JavaScript 控制台。
- **查看网页资源和站点数据**。打开 WebKit Inspector 后选择 Storage，查看该页面可用的 Cookies、Local Storage、Session Storage 等。
- **切换网页开发者工具**。在 WebKit Inspector 中使用 Elements、Network、Sources 等面板。
- **拾取网页元素**。从 0.1.0-preview.38 起，按 Ctrl+Shift+C 或从「… → 开发与诊断」启动。鼠标悬停预览元素，点击后在 Elements 中检查。选择中的点击由检查器处理。按 Esc 或切换网页可取消。
- **右键检查元素**。从 0.1.0-preview.47 起，在网页元素上右键选择「检查元素」，直接在 Elements 定位该节点。开发者工具会在空间允许时停靠到当前标签。停用插件或撤销开发者工具权限后，网页右键菜单会移除该入口。

常用的 Cookie、Local Storage 和 Session Storage 可直接从独立的「查看当前站点数据」命令打开。[站点数据](./site-data)

插件在用户触发的命令中使用 `devtools.open` 打开指定面板，可通过 `placement` 选择 `docked`、`window` 或 `preferred`。`preferred` 沿用当前工具的位置，新打开时使用保存的默认方式。传入 `panel: "elements"` 会开始拾取。`devtools.toggle` 切换当前标签的工具。命令绑定触发时的页面，网页切换后自动失效。

## 响应式预览

从 0.1.0-preview.67 起，在已加载的网页按 Ctrl+Shift+E，或从「… → 开发与诊断 → 切换响应式预览」打开尺寸栏。输入宽度和高度后按 Enter 或点「应用」。点「旋转」交换宽高，点「关闭」恢复正常布局。

网页会按实际视口重新布局，CSS 媒体查询随尺寸变化。窗口不足以显示请求的尺寸时，尺寸栏会显示实际大小。预览作用于当前标签，调试工具在预览期间使用独立窗口。关闭预览或退出浏览器后恢复正常布局。设备类型、触摸输入和网络条件沿用当前环境。

插件可在具备 `page.inspect` 权限的用户命令中调用 `devtools.viewport({})` 切换预览，或传入 `{ size: { width, height } }` 打开并设置尺寸。宽度和高度接受 120 至 2400 CSS 像素。返回 `enabled`、`disabled` 或 `unavailable`。命令绑定触发时的网页。

## 强制刷新网页

从 0.1.0-preview.55 起，按 Ctrl+Shift+R 或 Shift+F5，或选择「… → 开发与诊断 → 强制刷新网页」，可让 WebKit 重新从源站请求当前页资源。F5 和 Ctrl+R 继续执行普通刷新。强制刷新作用于当前标签页，站点存储照常保留。

强制刷新只应用于触发命令时已加载的活动网页。网页有未提交输入或标签可能重提表单时，浏览器会保留当前内容并提示原因。停用或撤销开发者工具权限后，组合键沿用普通刷新。

## 查看网页源代码

在已加载的网页按 Ctrl+U，或选「… → 开发与诊断 → 查看网页源代码」。源码会在专属标签页打开，支持行号、自动换行和 Ctrl+F 查找。

系统插件从 WebKit 读取已加载的主文档，网页内的脚本执行和 DOM 变化可通过开发者工具检查。源码作为纯文本显示，浏览器不会再请求原网页。超过 512 KiB 的文档显示开头并标注截断。原网页导航或关闭后，源码内容会从面板清除。

## 网页另存为 HTML

从 0.1.0-preview.39 起，在已加载的 HTML 网页按 Ctrl+S，或从「… → 标签与页面 → 网页另存为 HTML」选择保存位置。系统保存对话框会确认覆盖。成功保存的普通窗口文件可在下载页查看。

副本包含最多 16 MiB 的已加载主文档，写为 UTF-8 HTML。图片、样式和脚本等独立资源沿用文档中的链接。网页在确认保存前已切换时，需从原网页重新发起。

原生命令声明 `page.save`，调用 `page.saveHtml` 并传入 `{}`。保存路径和网页内容由浏览器处理。配置页无需读取这些数据。
