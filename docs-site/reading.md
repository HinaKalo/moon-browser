# 查找、缩放与全屏

按 Ctrl+F 或从 Ctrl+K 命令面板选择「页内查找」。输入文字后，WebKit 高亮当前标签中的匹配项。按 Enter 查找下一个，Shift+Enter 查找上一个，Esc 关闭查找栏。切换标签或打开其他页面会关闭当前查找栏。

按 Ctrl++、Ctrl+- 放大或缩小页面，Ctrl+0 恢复 100%。页面缩放调整网页排版，工具栏大小由 Windows 的 DPI 设置控制。浏览器在本机保存 HTTP(S) 站点的比例。协议、主机或端口不同的页面有各自的设置。

从 0.1.0-preview.36 起，在网页中按 F11 或选择「… → 标签与页面 → 切换浏览器全屏」。网页占满窗口所在的显示器。按 F11、Esc，或把鼠标移到屏幕上方中央并点击「退出全屏」，可以恢复原窗口位置和大小。聚焦地址栏或打开新标签页也会退出全屏。

## 插件 API

系统插件 MoonReading 在清单中声明 `page.reading`。开发者可以通过同一权限提供自己的查找或缩放命令。

- `reading.find` 打开触发命令的活动标签的查找栏，无参数，返回是否打开。
- `reading.zoom` 接收 `{ action: "increase" | "decrease" | "reset" }`，返回新的整数百分比。活动页不可用时返回 `null`。
- `window.toggleFullscreen` 独立使用 `window.fullscreen` 权限，接收 `{}`。返回 `true` 表示已进入全屏，`false` 表示已退出，`null` 表示原活动页面已切换或当前窗口不可用。

这些方法只能在用户触发的原生命令中调用。查找文字和匹配结果在浏览器窗口内处理。停用插件会停用对应的快捷键和命令，已保存的缩放比例仍会恢复。
