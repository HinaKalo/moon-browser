# 浏览历史

从 `0.1.0-preview.8` 起，浏览器随包提供 `moon.history` 系统插件。按 Ctrl+H、通过命令面板搜索「历史记录」，或在工具栏的插件菜单打开历史页。

历史按访问日期显示。搜索框匹配标题和网址，点记录在新标签页打开，点「移除」删除该条记录。「清空记录」需要再次确认。

从 0.1.0-preview.61 起，可按今天、昨天或最近 7 天筛选，再用标题或网址缩小范围。日期按当前系统时区计算，最近 7 天包含今天和前 6 天。

从 0.1.0-preview.77 起，可切到「按网站」，查看每个网站的匹配访问次数与最近访问时间。点击网站展开记录。网站按协议、主机和端口分组，因此 HTTP、HTTPS 和非默认端口各自显示。搜索和日期筛选在两种视图中都有效。筛选条件相同时，返回网站列表会保留已加载的条目。

勾选记录后点击「移除所选…」，确认时会显示选中数量。「选择已显示记录」只选择当前已加载的条目，最多 100 条。加载更多会保留当前选择，更改筛选条件会清空选择。「清空记录」仍作用于整个配置文件的浏览历史。

记录保存在当前浏览器配置文件中，最多保留最近 1,000 条，浏览器不会上传历史。停用插件或撤销「允许管理浏览历史」会停止记录后续访问，已有记录保留。页面加载成功后记录访问，浏览器后台卸载后自动恢复的页面不会因此增加访问记录。
