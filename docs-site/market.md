# 插件市场

用工具栏「… → 插件市场」或 Ctrl+K 打开，地址为 `moon://market/`。搜索插件名、ID 或功能说明，卡片会显示用途、所需权限和开发文档入口。

页面布局由浏览器提供，目录来自 Moon 上的固定 HTTPS 源。当前目录收录随安装包提供的系统插件。

## 管理已安装的插件

从 0.1.0-preview.28 起，可从新标签页、工具栏「… → 管理插件」或 Ctrl+K 打开管理页，地址为 `moon://plugins/`。可以按名称或插件 ID 搜索，筛选内置和本地插件，并查看命令与快捷键。选中插件后可启停、调整它声明的权限，或打开专属设置页。启用插件及授予新权限时，浏览器会显示原生确认。

管理页与插件市场可互相跳转。设置页由插件自行提供，用于功能配置。隐私窗口不提供全局插件管理入口。
