## 开始开发

当前预览版可以加载本地 Windows EXE 插件。先按快速开始运行随附示例，再用[预览版协议参考](./protocol-v1)接入自己的程序。下一版 API 草案面向公开 SDK，草案中的接口尚未在浏览器中开放。
