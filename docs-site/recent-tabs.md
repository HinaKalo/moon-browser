# 最近关闭的标签

按 Ctrl+Shift+T 恢复最近关闭的网页。在 Ctrl+K 命令面板搜索「最近关闭的标签」，可按标题和站点选择一项恢复，或清空列表。

列表在当前浏览器会话中保留最近 12 项。浏览器优先恢复 WebKit 的前进后退记录。若网页地址可安全重载但未能保存 WebKit 状态，则重新加载该地址。含有未保存交互、非 GET 导航或活动下载的标签会跳过。停用此系统插件或撤销权限时，浏览器会清空列表。

## 插件 API

声明 `tabs.closed.manage` 可调用 `tabs.closed.list`、`tabs.closed.reopen` 和 `tabs.closed.clear`。列表返回短期 ID、标题和站点来源。用于恢复的导航状态保留在宿主进程内。

从原生命令或活动插件页面调用 `tabs.closed.reopen`。传入 `{ id }` 恢复指定条目，传入 `{}` 恢复最近一项。条目在恢复后从列表移除。
