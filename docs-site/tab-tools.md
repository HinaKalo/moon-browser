# 固定与静音标签

在侧栏右键点击一个标签，可固定、取消固定、静音或取消静音。操作针对右键点击的标签，因此可以直接管理后台页。「… → 标签与页面」也可操作当前标签。

- 固定的网页排在侧栏顶部，并以图钉标识。最多固定 24 个。关闭固定标签可使用右键菜单。
- 重启时，浏览器把可以通过 HTTP(S) 安全重新打开的已固定网页放回原位。选中后才加载。内存调度仍能回收符合条件的固定后台页。
- 单标签静音由 WebKit 应用到该页的音频输出，切换页面或重建网页视图后继续生效。状态随标签关闭、退出浏览器或停用标签管理插件结束。

## 插件 API

声明 `tabs.organize` 权限后，用户触发的 EXE 命令可以调用 `tabs.togglePinned` 和 `tabs.toggleMuted`，参数均为空对象。宿主绑定发起命令的标签。方法也可以通过命令清单绑定到主菜单入口。

固定操作返回 `pinned`、`unpinned`、`limitReached` 或 `saveFailed`。静音操作返回 `muted` 或 `unmuted`。标签已关闭或不适用时返回 `unavailable`。
