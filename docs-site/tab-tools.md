# 标签管理

在侧栏右键点击一个标签，可固定、静音、复制或关闭标签。操作针对右键点击的标签，因此可以直接管理后台页。「… → 标签与页面」也可操作当前标签。

- 固定的网页排在侧栏顶部，并以图钉标识。最多固定 24 个。关闭固定标签可使用右键菜单。
- 从 0.1.0-preview.37 起，按住标签并拖到目标行的上半部或下半部，可将标签插入该行前后。靠近侧栏列表边缘会自动滚动。按 Esc 取消。也可用 Ctrl+Shift+PageUp 或 Ctrl+Shift+PageDown 移动当前标签。拖动保留当前页和已加载网页，固定区内的顺序会保存。
- 重启时，浏览器把可以通过 HTTP(S) 安全重新打开的已固定网页放回原位。选中后才加载。内存调度仍能回收符合条件的固定后台页。
- 单标签静音由 WebKit 应用到该页的音频输出，切换页面或重建网页视图后继续生效。状态随标签关闭、退出浏览器或停用标签管理插件结束。
- 「复制标签」打开该页面的副本，可用时一并保留前进和后退记录。已输入内容、非 GET 提交以及正在加载的页面会禁用复制。可用「复制标签网址」将当前已提交的网址放入系统剪贴板。
- 「关闭其他标签」整理整个侧栏，「关闭下方标签」只处理所点标签下方的条目。固定标签和仍受保护的标签会保留。已关闭且可恢复的网页仍可从「最近关闭的标签」找回。
- 右键点击网页中的 HTTP(S) 链接，可在后台标签打开或复制链接地址。新的后台标签在选中时加载，原页面保持当前状态。
- 从 0.1.0-preview.84 起，在网页中选中一段文字，再右键选择「复制所选文字的链接」。在支持文本片段的浏览器中打开该链接，会滚动到所选文字。

## 搜索打开的标签

从 0.1.0-preview.60 起，按 Ctrl+Shift+A 或选择「… → 标签与页面 → 搜索打开的标签」。输入标题或网址的任意一部分，可筛选当前窗口的标签。用上下方向键选择后按 Enter，或点击结果，即可切到原标签。按 Esc 关闭。

折叠组的成员和已卸载的标签也可搜索。选中后会展开所在组，并按需加载页面。隐私窗口仅显示本窗口的标签。搜索窗沿用浏览器主题。

## 多选标签

从 0.1.0-preview.87 起，按住 Ctrl 点击侧栏标签可增减选择，按住 Shift 点击可选择一段范围。侧栏显示选中的数量，当前网页保持在原位置。范围按照侧栏顺序计算，折叠组的成员会跳过。

右键点击已选中的标签，选择「关闭所选标签」。固定标签、仍在加载或播放的网页、有未提交输入的页面和其他受保护标签会保留。按 Esc、单击标签，或从右键菜单选择「取消选择」可清除选择。

## 标签组

从 0.1.0-preview.41 起，右键普通标签可新建标签组，再把其他标签拖到组标题或用「移入标签组」归类。点击组标题可折叠或展开，切换到组内标签会展开该组。也可将单个标签移出组。固定标签保持在独立分区。

从组标题的右键菜单打开「管理标签组」，可以改名、选色、折叠或解散。解散保留组内的标签页。恢复上次会话时，会重建其中可恢复网页的分组、颜色和折叠状态。

从 0.1.0-preview.88 起，右键多选中的任一标签，打开「将所选标签移入标签组」，可以新建组或选择已有组。也可以从右键菜单将所选标签移出各自所在的组。固定标签留在固定区，操作期间当前网页保持打开。将当前页移入折叠组时，该组会展开。

### 标签组 API

`tabs.groups` 授权后，用户触发的原生命令传入 `{}`，可调用 `tabs.groups.create`、`tabs.groups.removeTab` 或 `tabs.groups.open`。宿主为命令绑定目标标签，`open` 将目标传给插件配置页。

用户触发的命令同时拥有 `tabs.groups` 和 `tabs.manage` 授权时，可调用 `tabs.groups.applySelection({ action, id? })`。使用 `create` 创建组，`assign` 移入指定组，`remove` 移出各自所在的组。仅 `assign` 需要现有组的 `id`。宿主绑定命令启动时的选择。返回 `{ state, moved, kept }`，其中 `kept` 统计保留的固定标签。选择或目标失效时返回 `unavailable`，组数达到上限时返回 `limitReached`。

活动配置页调用 `tabs.groups.list` 获取 `{ groups, assigned, assignable }`，其中组含 `id`、`name`、`color`、`collapsed` 和 `members`。调用 `tabs.groups.assign({ id })` 移动绑定标签，`id: 0` 表示移出。用 `tabs.groups.update({ id, name, color, collapsed })` 修改，用 `tabs.groups.dissolve({ id })` 解散。颜色为 `indigo`、`teal`、`amber`、`rose` 或 `slate`。

## 标签操作 API

声明 `tabs.organize` 权限后，用户触发的 EXE 命令可以调用 `tabs.togglePinned` 和 `tabs.toggleMuted`，参数均为空对象。宿主绑定发起命令的标签。方法也可以通过命令清单绑定到主菜单入口。

声明 `"tabDrop": true` 的 [排序命令](./command-contributions#标签排序) 可调用 `tabs.reorder`。参数为空对象。宿主根据本次用户操作确定位置。

固定操作返回 `pinned`、`unpinned`、`limitReached` 或 `saveFailed`。静音操作返回 `muted` 或 `unmuted`。标签已关闭或不适用时返回 `unavailable`。

复制和批量关闭使用独立的 `tabs.manage` 权限，且须由用户命令触发。

| 方法 | 参数与结果 |
| --- | --- |
| `tabs.duplicate` | 传入 `{}`。返回 `duplicated`、`limitReached` 或 `unavailable`。 |
| `tabs.copyAddress` | 传入 `{}`。返回 `copied`、`clipboardBusy` 或 `unavailable`。网址由宿主写入剪贴板。 |
| `tabs.closeGroup` | 传入 `{ scope }`，值为 `others`、`below` 或 `selected`。返回 `{ closed, kept }`。目标已关闭时返回 `null`。使用 `selected` 时，宿主在用户触发命令时绑定多选状态。选择为空或已改变时返回 `null`。 |
| `tabs.openSearch` | 传入 `{}`。用户命令的目标仍为活动标签时打开本窗口的搜索面板，返回是否打开。搜索词、匹配结果和选择都由浏览器处理。 |
