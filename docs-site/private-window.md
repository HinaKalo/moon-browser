# 隐私浏览

按 `Ctrl+Shift+N`，或从「… → 隐私与安全 → 新建隐私窗口」打开。地址栏旁的「隐私浏览」标识会持续显示。

同一隐私窗口的标签共享 Cookie、Local Storage 和 IndexedDB。每个新隐私窗口从空白会话开始，关闭窗口就结束这次会话。本版 WebKit 的 Cache Storage 条目可能在同一隐私窗口的其他标签中不可见。隐私窗口里的网页访问记录不会加入普通浏览历史。手动保存的下载文件会保留。

隐私窗口只加载随包提供、可在临时会话中运行的工具。普通配置里的用户脚本、自装插件和固定标签不会带入隐私窗口。开发者工具、站点数据检查、查找与临时缩放仍可使用。

隐私浏览管理的是 Moon Browser 的本机会话。访问的网站和所用网络仍能看到正常的访问请求。

## 插件 API

原生插件声明 `privacy.privateWindow` 权限，获得授权后，可以在用户触发的命令中调用 `privacy.openPrivateWindow`。传入 `{}`。成功启动独立窗口进程时返回 `true`。
