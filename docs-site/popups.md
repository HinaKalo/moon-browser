# 网站弹窗

在地址栏左侧的站点菜单中选择「管理网站弹窗」，也可从「… → 隐私与安全」或 Ctrl+K 打开。网站触发自动弹窗时，浏览器默认拦截。直接点击打开新标签的链接照常使用。

从原网页打开设置时，页面会显示当前网站以及最近拦截的目标站点。点「打开一次」并确认后，只打开这一条链接。原网页导航或关闭后，旧弹窗记录会清除。

可为单个网站允许自动弹窗、阻止新窗口，或恢复默认。规则按发起标签的主文档来源保存，分别区分 HTTP、HTTPS 和端口。允许自动弹窗需要原生确认，适用于该来源在前台打开的标签。隐私窗口使用默认规则。

弹窗目的地作为独立标签打开，适用于直接带有 HTTP(S) URL 的请求。依赖空白窗口、表单 POST 或跨窗口脚本控制的流程仍需内核级的新窗口支持。
