# 站点设置

在地址栏左侧的站点菜单中选择「站点设置」，也可从「… → 隐私与安全」或 Ctrl+K 打开。通过网页打开时，面板会显示该网站的来源。

从 0.1.0-preview.69 起，「当前网站」集中显示弹窗、自动播放、声音和缩放。点规则可直接定位编辑，点「静音此网站」或「取消网站静音」立即应用到该来源。「查看站点数据」和「打开控制台」由相应的系统插件处理，也可点「返回网页」切回原标签。原网页导航或关闭后，旧工具入口会失效。

具备 `popups.manage` 权限的活动插件页可调用 `siteSettings.current({})` 获取绑定站点的 `origin`、`revision` 和可用的 `tools`。自动播放、声音和缩放分别按对应权限返回。通过 `siteSettings.openTool({ revision, tool })` 可请求 `page`、`data` 或 `console`，返回请求是否已受理。数据和控制台需要目标系统插件保持启用并获授权。

## 网站弹窗

网站触发自动弹窗时，浏览器默认拦截。直接点击打开新标签的链接照常使用。

从原网页打开设置时，页面会显示当前网站以及最近拦截的目标站点。点「打开一次」并确认后，只打开这一条链接。原网页导航或关闭后，旧弹窗记录会清除。

可为单个网站允许自动弹窗、阻止新窗口，或恢复默认。规则按发起标签的主文档来源保存，分别区分 HTTP、HTTPS 和端口。允许自动弹窗需要原生确认，适用于该来源在前台打开的标签。隐私窗口使用默认规则。

弹窗目的地作为独立标签打开，适用于直接带有 HTTP(S) URL 的请求。依赖空白窗口、表单 POST 或跨窗口脚本控制的流程仍需内核级的新窗口支持。

## 媒体自动播放

从 0.1.0-preview.48 起，可按网站选择默认、允许、仅允许静音或阻止自动播放。允许有声自动播放需要在系统对话框中确认。选择「阻止」时，视频和有声媒体需要用户点击才能播放。WebKit 允许已静音的 `<audio>` 元素保持无声播放。设置应用于新打开或刷新的顶层网页。恢复默认会移除该网站的例外。隐私窗口沿用 WebKit 的默认行为。

SDK 提供 `siteSettings.autoplay.get` 和 `siteSettings.autoplay.set`。插件需要独立的 `siteSettings.autoplay` 权限。保存规则的来源包含协议、主机和非默认端口，路径会被忽略。

## 网站静音

从 0.1.0-preview.49 起，地址栏的站点菜单和 Ctrl+K 提供「切换网站静音」。规则立即应用于当前配置中该来源的普通标签页，并应用于以后访问同一来源的网页。侧栏显示静音图标，站点菜单分别显示网站静音和标签静音的状态。站点设置的「网站声音」可查看和取消已有规则。

网站静音与单标签静音可以同时生效。只有两项都解除，标签页才恢复声音。网站仍可开始播放媒体并显示播放进度。规则按协议、主机和端口保存，隐私窗口使用独立的标签静音。

## 网站缩放

从 0.1.0-preview.59 起，在「站点设置 → 网站缩放」查看、搜索和编辑已保存的比例。从网页进入时会自动填入该来源及其比例。保存后，同一来源已打开的普通标签页会即时调整。选择「恢复 100%」会删除该来源的例外，后续访问使用默认比例。

比例与页面缩放快捷键共用同一份设置。HTTP、HTTPS 和非默认端口各自保存。隐私窗口中的缩放只作用于当前标签页。插件通过 `siteSettings.zoom` 权限调用 `siteSettings.zoom.get` 和 `siteSettings.zoom.set`。

## 内核能力

目前 Windows 发行包固定使用 Playwright WebKit build 2388。对该二进制开启宿主媒体设备设置后，在安全的本机网页中仍未暴露 `navigator.mediaDevices`。摄像头和麦克风规则需要支持此网页接口的 Windows WebKit 构建。
