# Moon Browser 0.1.0-preview.72

- Lua 用户脚本的 DOM 操作改用 WebKit 的隔离环境，避开标签恢复后在后退过程中触发过的异步脚本执行崩溃。
- 保留 WebKit 的会话快照与前进、后退历史，也保留 Lua 编辑器的保存后热重载。
- 关闭窗口时，尚有子资源在加载的已提交网页也可保存在上次会话。
- 站点数据插件支持逐条删除 IndexedDB 记录，并在操作后保留当前记录页。接口为 `siteData.removeRecord`。
- 书签管理支持跨页选择和批量在后台打开。切换到新标签时才加载网页。接口为 `bookmarks.openMany`。
