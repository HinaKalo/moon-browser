# Moon Browser 0.1.0-preview.16

- 内置「浏览器任务管理器」，可从内存诊断入口或 Ctrl+Shift+M 打开。
- 按标签或 PID 查看状态与内存，显示卸载前后的私有提交内存。可手动卸载符合现有保护规则的后台标签。

## Windows 本地验收

`python tests/smoke.py <MoonBrowser.exe> --pressure --ui` 使用 128 MiB 压力阈值和 96 MiB 目标值触发回收。50 个标签中有 48 个已卸载，剩余 2 个受保护。该轮卸载前后进程树私有提交内存为 1398.8 MiB 和 1393.9 MiB。窗口首显 172 ms，测试页首次绘制 266 ms，20 次热切换的 p95 为 2.83 ms。

交互验收覆盖原生入口、24 条分页、按 PID 合计内存、拒绝卸载受保护标签，以及手动卸载后恢复。此次实际运行没有形成同 PID 的多个标签，重复 PID 合计由策略单元测试覆盖。
